# Hallucination-Aware-Malayalam-Abstractive-Summarization
Faithful Abstractive Malayalam Summarization using Multilingual Language Models — A comparative study of mBART, mT5, BLOOMZ, and Sarvam across zero-shot, few-shot, and fine-tuned settings, with ROUGE, BLEU, BERTScore, and XNLI-based faithfulness and hallucination evaluation.
