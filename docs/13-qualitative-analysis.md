# Qualitative Analysis

A qualitative analysis was performed using representative generated summaries from the fine-tuned mT5 model.

The samples were selected using sample-level faithfulness and hallucination scores obtained from the XLM-RoBERTa-Large NLI evaluation.

## Faithful Sample

The most faithful sample achieved:

- Faithfulness: 99.96%
- Hallucination: 0.05%

The generated summary preserves information from the source article with very high factual alignment.

## Hallucinated Samples

Highly hallucinated generated summaries were also examined.

The highlighted portions in the qualitative examples represent hallucinated content that is not supported by, or does not make sense according to, the source article.

This qualitative analysis provides an example-level interpretation of the factual consistency results obtained through the intrinsic NLI evaluation.
